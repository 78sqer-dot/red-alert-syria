# Red Alert Syria — الإنذار الأحمر سوريا

خريطة سوريا التفاعلية المباشرة للتنبيهات، تُغذّى من بوت تيليغرام: يستقبل البوت الخبر، ينشره في القناة [@Red_Alert_Syria](https://t.me/Red_Alert_Syria)، ويظهر فوراً على الخريطة لكل الزوار دون تحديث الصفحة.

## المزايا

**الموقع:** خريطة MapLibre بخط عربي (Noto Kufi Arabic) وحدود سوريا والمحافظات، علامات متحركة لكل نوع (مسيّرة وطيران حربي بمدار دوّار، وصواريخ وقصف مدفعي وهجوم ومدني وخبر عاجل بدوائر نابضة)، قائمة تنبيهات جانبية (أو لوحة سحب على الهاتف)، نافذة تفاصيل مع الإحداثيات والمشاركة (واتساب، تيليغرام، نسخ الرابط)، شريط أخبار متحرك، شريط «عاجل»، تصفية حسب النوع، طبقات (قياسي، قمر صناعي، تضاريس ثلاثية الأبعاد، القمم الجبلية، حدود المحافظات، تعتيم خارج سوريا)، وضع داكن وفاتح، العربية والإنجليزية، إشعارات المتصفح مع نغمات وصوت واهتزاز، جولة تعريفية، وتحديث لحظي عبر Server-Sent Events.

**البوت:** أزرار لكل نوع (خبر عاجل، مسيّرة، حربي، قصف مدفعي، هجوم، مدني، صواريخ)، ثم اختيار المحافظة ← المنطقة ← البلدة من قوائم (أكثر من 5,000 مكان سوري بالعربية والإنجليزية)، أو كتابة اسم البلدة للبحث، أو إرسال موقع من تيليغرام. معاينة قبل النشر، تحديد مدة التنبيه، إنهاء أو تمديد أو حذف التنبيه لاحقاً (ويتحدّث منشور القناة تلقائياً)، زر اللغة، إدارة المحررين، إحصاءات، وبلاغات من العامة تُرسل للمراجعة مع أزرار موافقة ورفض وحظر.

## الأمان

ترويسات أمان صارمة (CSP، HSTS، منع التضمين)، تحديد معدل الطلبات، ويب هوك تيليغرام محمي برمز سري، النشر محصور بالمالك والمحررين، تعقيم كل النصوص قبل عرضها، وتوكن البوت يُحفظ فقط كمتغير بيئة ولا يوجد في الكود.

## التشغيل

```bash
npm ci
BOT_TOKEN=xxxx OWNER_IDS=8270709633 npm run dev   # محلياً (long polling)
```

| المتغير | الوصف |
|---|---|
| `BOT_TOKEN` | توكن البوت من BotFather (سري) |
| `OWNER_IDS` | معرّفات المالكين المسموح لهم بالنشر، مفصولة بفواصل |
| `CHANNEL_ID` | القناة، افتراضياً `@Red_Alert_Syria` (البوت يجب أن يكون مشرفاً فيها) |
| `PUBLIC_URL` | رابط الموقع العام (على Render يُكتشف تلقائياً) |
| `TELEGRAM_BACKUP` | `false` لإيقاف النسخ الاحتياطي التلقائي إلى محادثة المالك |

## النشر على Render

الملف `render.yaml` جاهز: خدمة ويب Node، أمر البناء `npm ci --omit=dev`، أمر التشغيل `node server/index.js`. على Render يعمل البوت بوضع Webhook تلقائياً، ويحفظ نسخة احتياطية من البيانات في محادثة المالك على تيليغرام (رسالة مثبتة) تُستعاد بعد كل إعادة تشغيل.

## أوامر البوت

`/start` القائمة · `/active` التنبيهات النشطة · `/lang` اللغة · `/id` معرّفك · `/addeditor ID` و`/removeeditor ID` و`/editors` إدارة المحررين · `/stats` الإحصاءات · `/backup` نسخة احتياطية فورية.
