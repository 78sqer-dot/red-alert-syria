# Red Alert Syria | الإنذار الأحمر سوريا

خريطة تنبيهات لسوريا مرتبطة بقناة تيليغرام وبوتي نشر وتبليغ، بواجهة عربية وإنجليزية وتحديث مباشر دون إعادة تحميل الصفحة.

[الخريطة](https://red-alert-syria-q6k8.onrender.com/ar/) · [قناة تيليغرام](https://t.me/Red_Alert_Syria) · [دليل المشروع](docs/README.md)

## مكونات المشروع

- **الموقع:** خريطة تفاعلية، تفاصيل التنبيهات، البحث والتصفية، مشاركة الروابط وإشعارات المتصفح.
- **بوت النشر:** لوحة خاصة للمالك والمحررين لإعداد الأخبار ومراجعتها ونشرها وإدارتها.
- **بوت التبليغ:** استقبال بلاغات الجمهور وإرسالها للمراجعة، دون نشر مباشر من المبلّغ.
- **الخادم:** واجهة HTTP، بث مباشر عبر SSE، حفظ الحالة والنسخ الاحتياطي والمهام المجدولة.

التنبيه منسوب إلى مصدره، وليس ضمانًا لصحة الواقعة. المرجع الجغرافي التقريبي لا يعني موقع الحادث الدقيق أو نطاق خطر. اتبع تعليمات الجهات الرسمية والدفاع المدني.

## خريطة المستودع

| المسار | الغرض |
|---|---|
| `public/` | واجهة الموقع، الصور، الخطوط وملفات PWA |
| `server/` | خادم Express، البوتات، النشر، المراقبة والحفظ |
| `shared/` | منطق مشترك بين الخادم والواجهة |
| `data/` | بيانات الأماكن ومواعيد الفجر الثابتة |
| `test/` | اختبارات Node والانحدارات المعروفة |
| `scripts/` | البناء وأدوات البيانات والفحص والتطوير |
| `docs/` | أدلة التشغيل والمساهمة والملاحظات التاريخية |
| `.github/workflows/` | مهام GitHub المجدولة |
| `render.yaml` | تعريف خدمة Render |

`data/runtime/` حالة تشغيل خاصة، مستثناة من Git. لا ترفعها أو نسخ تيليغرام الاحتياطية إلى المستودع.

## البدء بالتطوير

استخدم Node.js 22 لمطابقة تعريف النشر الحالي.

```bash
npm ci
npm run build
npm test
```

هذه الخطوات تثبّت الاعتماديات وتجهّز ملفات المتصفح وتجري الاختبارات. لا تشغّل نسخة تطوير بتوكنات الإنتاج. للتجربة التفاعلية، استخدم بوتات وبيانات اختبار منفصلة ودليل [المساهمة والفحص](CONTRIBUTING.md).

| الأمر | الوظيفة |
|---|---|
| `npm run build` | نسخ اعتماديات المتصفح والخطوط إلى `public/` |
| `npm test` | تشغيل اختبارات Node |
| `npm run test:push-monitor` | اختبار أداء توزيع إشعارات المتصفح |
| `npm run sim` | محاكاة البوت للتطوير، راجع إعداداتها قبل التشغيل |
| `npm start` | تشغيل التطبيق والمهام المرتبطة به |

## الإعداد والنشر

أسماء المتغيرات في [`.env.example`](.env.example)، وإعداداتها التشغيلية الأساسية في [دليل Render والنقل الآمن](docs/RENDER_MIGRATION.md). لا تضع القيم السرية في Git أو Issues أو سجلات الاختبار. وجود `.env.example` لا يعني أن التطبيق يحمّل ملف `.env` تلقائيًا.

التطبيق خدمة Node واحدة. نشر نسخة ثانية بتوكنات الإنتاج قد يكرر العمل أو يغيّر Webhook. قد يؤدي الدفع إلى فرع الإنتاج المرتبط بـ Render إلى نشر تلقائي، لذلك اجمع التعديلات المراجعة في دفعة واحدة منسقة.

- البناء على Render: `npm ci --omit=dev`، ثم تجهيز ملفات المتصفح وفق إعداد الخدمة الفعلي.
- التشغيل: `node server/index.js`.
- فحص الصحة: `/api/health`.
- لا تعطل النسخ الاحتياطي أو تعيد تشغيل مهام الصيانة لمجرد ترتيب المستودع.

## مصادر البيانات والاعتماديات

تستخدم الواجهة MapLibre وOpenFreeMap وبيانات OpenStreetMap وGeoNames وgeoBoundaries، ومصادر خرائط وصور وخطوط أخرى بحسب الميزة. أبقِ الإسناد وشروط المصادر مع الملفات المستخدمة. يعلن `package.json` الترخيص MIT؛ لا يوجد ملف `LICENSE` مستقل حاليًا، وإضافته تتطلب التحقق من نص الحقوق والملكية، ولا يُفترض أن ترخيص الكود يغطي جميع البيانات والصور.
