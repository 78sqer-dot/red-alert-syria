# الإنذار الأحمر سوريا — Red Alert Syria

نسخة مبنية على فكرة موقع [redalert.com.lb](https://redalert.com.lb/ar/) (الإنذار الأحمر لبنان) لكن للخريطة السورية.
خريطة تنبيهات مباشرة داكنة، عربية RTL بالكامل، في **ملف واحد مكتفٍ ذاتياً** (`index.html`) — بدون أي اعتماد على خوادم أو مكتبات خارجية (الخط فقط يُحمَّل اختيارياً من Google Fonts).

## وضعان للتشغيل

| الوضع | الوصف |
|---|---|
| `demo` (افتراضي) | تنبيهات محاكاة تجريبية — يعمل فور فتح الملف |
| `live` | بيانات حقيقية من بوت تليغرام + قناة — انظر **DEPLOY.md** |

للتبديل إلى الوضع الحقيقي: افتح `index.html`، ابحث عن `⚙️ CONFIG` وعدّل:
```js
mode: 'live',
feedURL: 'https://your-worker.workers.dev/alerts',
reportURL: 'https://t.me/YourBot',
```
أو جرّب فوراً دون تعديل: أضف `?live=رابط-التنبيهات` إلى عنوان الصفحة.

> ⚠️ في وضع `demo` جميع التنبيهات بيانات محاكاة لأغراض التصميم والعرض فقط.

## المزايا

- **خريطة سوريا SVG مرسومة برماجياً**: المحافظات الـ14 بحدودها الإدارية الحقيقية (بيانات geoBoundaries) + الدول المجاورة + البحر المتوسط
- **68 مدينة وبلدة** تظهر تدريجياً مع التكبير
- **10 أنواع تنبيهات** بأيقونات وألوان: غارة جوية، مسيّرة، طيران حربي، مروحية، قصف مدفعي، صواريخ، اشتباكات، إنذار إخلاء، قطع طريق، زلزال
- **صفارة إنذار** مركّبة عبر Web Audio + اهتزاز + إشعارات متصفح
- **شريط تنبيهات جانبي** بأوقات نسبية — النقر يكبّر إلى الموقع ويفتح تفاصيله
- **بانر أحمر** + عدّادات (تنبيهات اليوم / النشطة الآن / الساعة)
- **تصفية** حسب النوع والمحافظة (أو بالنقر على المحافظة في الخريطة)
- **الإعدادات**: الصوت، الاهتزاز، المحافظات المتابَعة | **الطبقات** + دليل ألوان
- **خريطة تفاعلية**: سحب، تكبير بالعجلة/القرص/النقر المزدوج، مقياس رسم ديناميكي
- **جولة تعريفية** + نوافذ «بلّغ» و«تبرّع» و«عن المنصّة»
- تصميم متجاوب للجوال

## الربط بالحقيقة (بوت تليغرام + قناة + استضافة ٢٤/٧)

الملفات الجاهزة للنشر موجودة في المستودع:

| الملف | الدور |
|---|---|
| `index.html` | الموقع — يُرفع إلى **GitHub Pages** (استضافة مجانية ٢٤/٧) |
| `telegram/worker.js` | الخادم الخلفي لـ **Cloudflare Worker** (موصى به — مجاني): بوت بلاغات بأزرار + موافقة المشرفين + نشر للقناة + واجهة `/alerts` |
| `telegram/bot.js` | بديل **Node.js** بدون مكتبات (Railway / Render / VPS) بنفس الوظائف |
| `DEPLOY.md` | **دليل كامل خطوة بخطوة**: BotFather، القناة، GitHub Pages، Cloudflare، الربط |

تنسيق التنبيه الواحد من الخادم:
```json
{ "id":1695000000000, "type":"strike", "gov":"حلب", "city":"حلب",
  "area":"الفرقان", "ts":1695000000000, "until":1695000420000, "ended":false }
```

## التشغيل المحلي

افتح `index.html` مباشرة في المتصفح — لا حاجة لأي شيء آخر. أو:

```bash
cd red-alert-syria && python3 -m http.server 8080
```

## البنية

```
index.html          ← الموقع النهائي (يُولَّد)
mapdata.json        ← بيانات الخريطة المُجمَّعة (paths + مدن + شبكة)
telegram/
  worker.js         ← خادم Cloudflare Worker (بوت + قناة + API)
  bot.js            ← بوت Node.js بديل (بدون مكتبات)
DEPLOY.md           ← دليل الربط والتشغيل ٢٤/٧
src/
  style.css         ← التنسيقات
  body.html         ← هيكل الصفحة
  app.js            ← منطق التطبيق (يحتوي __MAPDATA__ و CONFIG)
  assemble.py       ← دمج المصادر في index.html
  build_map.py      ← تحويل GeoJSON (geoBoundaries) إلى SVG paths
  *.geojson         ← البيانات المصدرية (سوريا ADM1 + جيران ADM0)
```

إعادة البناء بعد أي تعديل:

```bash
python3 src/build_map.py && python3 src/assemble.py
```
